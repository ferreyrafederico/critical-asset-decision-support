# Critical Asset Decision Support

## 🇬🇧 English Version

### Overview

This repository presents a structured Decision Support System for managing operational continuity in critical industrial assets under uncertainty.

The project simulates a realistic business case where a company must decide whether to interrupt operations for preventive maintenance or continue running a critical asset while facing uncertain failure risk.

The objective is to demonstrate:

- Structured decision modeling under uncertainty
- Identification of non-tolerable risks
- Quantitative evaluation (expected value and dynamic risk)
- Executive-level communication of technical decisions
- A professional framework applicable across industries

This is a **demonstration case**, designed to reflect real-world industrial decision environments.  
It is not based on a specific company but follows realistic operational and economic logic.

---

### Repository Structure

The repository is organized into two language versions:

/es → Full case documentation in Spanish  
/en → Full case documentation in English  

Each folder contains the complete structured case:

1. Context definition  
2. Decision framing and alternatives  
3. Simple quantitative model  
4. Dynamic risk analysis  
5. Executive decision report  
6. Technical appendix  

---

### Purpose

This project serves as:

- A portfolio demonstration of structured decision analysis
- A template adaptable to real industrial scenarios
- A foundation for future automation using AI or workflow systems

## 🇪🇸 Versión en Español

### Descripción General

Este repositorio presenta un Sistema de Soporte a Decisiones para la continuidad operativa de activos industriales críticos bajo incertidumbre.

El proyecto simula un caso empresarial realista en el cual una empresa debe decidir si interrumpir la operación para realizar mantenimiento preventivo o continuar operando asumiendo un riesgo incierto de falla.

El objetivo es demostrar:

- Modelado estructurado de decisiones bajo incertidumbre
- Identificación de riesgos no tolerables
- Evaluación cuantitativa (valor esperado y riesgo dinámico)
- Comunicación ejecutiva de decisiones técnicas
- Un marco profesional aplicable a múltiples industrias

Este es un **caso de demostración**, diseñado para reflejar entornos industriales reales.  
No está basado en una empresa específica, pero sigue una lógica operativa y económica realista.
